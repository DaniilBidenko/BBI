# Подключение заявок к Bitrix24

Заявки с форм сайта (контакты и главная страница) отправляются в CRM Bitrix24 как лиды. Код уже подготовлен; чтобы включить отправку, нужны данные от владельца Bitrix24.

---

## Что нужно от заказчика (Bitrix24)

Нужен **URL входящего webhook** с доступом к CRM (создание лидов).

### Как им получить в Bitrix24

1. Войти в Bitrix24 под администратором (или пользователем с правами на настройку приложений).
2. Перейти: **Настройки** → **Разработчикам** → **Входящий webhook** (или **Другое** → **Входящий webhook**).
3. Создать новый входящий webhook:
   - **Права**: включить минимум **CRM (crm)**.
   - Сохранить — Bitrix24 покажет **URL вида**:
     `https://ваш-портал.bitrix24.ru/rest/1/xxxxxxxxxxxx/`
4. Скопировать этот URL **целиком** (без добавления пути вроде `crm.lead.add` — его дописывает наш сервер).

### Что передать вам

Один параметр:

| Параметр | Описание |
|----------|----------|
| **URL входящего webhook** | Полный URL, например: `https://company.bitrix24.ru/rest/1/abc123def456/` |

Его нужно добавить в переменные окружения (на сервере или в хостинге) как:

```bash
BITRIX24_WEBHOOK_URL=https://company.bitrix24.ru/rest/1/abc123def456/
```

После сохранения и перезапуска приложения заявки с сайта начнут создавать лиды в Bitrix24.

---

## Какие данные уходят в лид

- **Название лида (TITLE)** — компания или «Заявка с сайта».
- **Имя (NAME)** — имя из формы.
- **Компания (COMPANY_TITLE)** — компания из формы.
- **Телефон (PHONE)** — если в поле «Контакт» нет символа `@`.
- **Email (EMAIL)** — если в поле «Контакт» есть `@`.
- **Комментарий (COMMENTS)** — текст запроса + оборот/размер команды (если указаны).
- **Источник (SOURCE_DESCRIPTION)** — «Сайт BBI».

---

## Проверка

- Если `BITRIX24_WEBHOOK_URL` не задан: форма отправится без ошибки, но лид в Bitrix24 не создаётся (ответ API 503).
- После подстановки URL новые заявки должны появляться в CRM как лиды.
